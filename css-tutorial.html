1. What is CSS?

CSS stands for Cascading Style Sheets. It controls how HTML elements look on a webpage.

HTML

Creates webpage structure.

CSS

Controls colours, layout and design.

JavaScript

Adds interactive behaviour.

Browser

Displays the finished webpage.

HTML creates the structure, CSS makes it attractive, and JavaScript makes it interactive.

2. CSS syntax

A CSS rule contains a selector and a declaration block.

h1 {
  color: blue;
  font-size: 32px;
}
  • Selector: chooses the HTML element.
  • Property: what you want to change.
  • Value: the setting you choose.

CSS can be added inline, inside a style element, or in an external .css file.

3. CSS selectors

Selectors help you target HTML elements.

/* Element selector */
p {
  color: white;
}

/* Class selector */
.card {
  background: navy;
}

/* ID selector */
#heading {
  font-size: 30px;
}
  • p selects paragraph elements.
  • .card selects elements with class="card".
  • #heading selects the element with id="heading".

4. Colours, backgrounds and fonts

CSS can change text colour, background colour, font size and font family.

body {
  background-color: #10172a;
  color: white;
  font-family: Arial, sans-serif;
}

h1 {
  color: cyan;
  font-size: 36px;
}

p {
  line-height: 1.7;
}
You can use colour names, HEX values, RGB and other CSS colour formats.

5. Understanding the CSS box model

Every normal HTML element can be understood as a box with content, padding, border and margin.

.card {
  width: 250px;
  padding: 20px;
  border: 2px solid white;
  margin: 15px;
  box-sizing: border-box;
}

Content

The text or other material inside.

Padding

Space between content and border.

Border

The edge around the element.

Margin

Space outside the border.

6. CSS Flexbox

Flexbox helps arrange elements in a row or column.

.container {
  display: flex;
  justify-content: center;
  align-items: center;
  gap: 15px;
  flex-wrap: wrap;
}
  • display: flex creates a flex container.
  • justify-content controls alignment along the main axis.
  • align-items controls alignment along the cross axis.
  • gap adds space between items.
  • flex-wrap allows items to move onto another line.

7. CSS Grid

Grid is useful for layouts with rows and columns.

.grid-container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 15px;
}

This creates three equal-width columns with space between them.

Use Flexbox for many one-dimensional layouts and Grid for two-dimensional layouts. They can also work together.

8. Responsive web design

Responsive design helps a webpage adapt to different screen sizes.

.cards {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
}

@media (max-width: 700px) {
  .cards {
    grid-template-columns: 1fr;
  }
}

When the screen width is 700 pixels or less, the cards become one column.

9. Build your first styled webpage

Create an HTML file and add this example. Save it as my-page.html and open it in your browser.

<!doctype html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>My First Styled Page</title>
  <style>
    body {
      font-family: Arial;
      background: #eef2ff;
      padding: 30px;
    }

    .card {
      background: white;
      padding: 25px;
      border-radius: 12px;
      max-width: 450px;
      margin: auto;
    }

    h1 {
      color: #3949ab;
    }
  </style>
</head>
<body>
  <div class="card">
    <h1>Hello, CSS!</h1>
    <p>I am learning web design.</p>
  </div>
</body>
</html>

12. Frequently asked questions

Is CSS a programming language?

CSS is a style sheet language used to describe how HTML documents should look.

Can I learn CSS for free?

Yes. You can practise CSS using a free text editor and browser.

What should I learn before CSS?

Basic HTML knowledge makes learning CSS easier.

What should I learn after CSS?

JavaScript is a useful next step for adding interactive behaviour to webpages.

What is the difference between Flexbox and Grid?

Flexbox is mainly one-dimensional, while Grid is designed for rows and columns together.
