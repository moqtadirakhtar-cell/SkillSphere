1. What is JavaScript?

JavaScript ek programming language hai jo websites ko interactive banati hai.

  • Buttons ko working banana
  • Calculations karna
  • Games banana
  • User ke input ka response dena

2. Variables

Variables data store karne ke liye use hote hain.

let name = "Student";
const age = 12;

console.log(name);
console.log(age);

let ki value change ho sakti hai. const ko dobara assign nahi kar sakte.

3. Data Types

let name = "Moqtadir"; // String
let age = 12;           // Number
let isStudent = true;    // Boolean
let score = null;       // Null

Data types batate hain ki variable mein kis type ka data store hai.

4. Operators

let a = 10;
let b = 5;

console.log(a + b); // 15
console.log(a - b); // 5
console.log(a * b); // 50
console.log(a / b); // 2

Operators calculations aur comparisons karne ke kaam aate hain.

5. Conditions (if / else)

let marks = 80;

if (marks >= 40) {
  console.log("Pass");
} else {
  console.log("Fail");
}

Conditions ke through program decisions leta hai.

6. Functions

function greet() {
  console.log("Hello Student!");
}

greet();

Function reusable code ka block hota hai, jise baar-baar call kar sakte hain.

7. Loops

for (let i = 1; i <= 5; i++) {
  console.log(i);
}

Loops kisi kaam ko baar-baar repeat karne ke liye use hote hain.

9. Practice Challenge

Khud se ek program banane ki koshish karo:

  • Ek variable mein apna naam store karo.
  • Ek variable mein apni class store karo.
  • Console mein dono print karo.
  • Ek function banao jo welcome message dikhaye.

10. What's Next?

Ab tum JavaScript ke basic concepts jaante ho. In concepts ka use karke calculator, quiz, interactive webpage aur chhote projects bana sakte ho.
