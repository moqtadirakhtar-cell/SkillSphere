1. What is HTML?

HTML stands for HyperText Markup Language. It is the standard markup language used to create and structure webpages.

HTML tells the browser how webpage content is organised, including headings, paragraphs, links, images and lists.

HTML

Creates the structure of a webpage.

CSS

Controls colours, design and layout.

JavaScript

Adds interactive features.

Browser

Displays your webpage.

You can start learning HTML using a free text editor and a web browser.

2. Basic HTML Structure

Every standard HTML document follows a basic structure. Here is a simple example: 

<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta name="viewport"
    content="width=device-width, initial-scale=1.0">

    <title>My First Website</title>
</head>

<body>

    <h1>Hello World!</h1>

    <p>This is my first webpage.</p>

</body>
</html>
  • DOCTYPE declares the HTML version.
  • html is the root element.
  • head contains page information.
  • title sets the browser-tab title.
  • body contains visible content.

3. Common HTML Tags

4. How to Add Links and Images

HTML Links

The anchor tag creates a clickable link. 

<a href="https://example.com">
Visit Example
</a>

HTML Images

The image tag displays an image on your webpage. 

<img
src="study.jpg"
alt="Books on a study desk"
>

The alt attribute provides alternative text for people who cannot see the image.

Unordered List

Ordered List

6. HTML Forms

Forms are used to collect information from visitors. Here is a simple HTML form example. 

<form>

    <label for="name">Your Name</label>

    <input
    type="text"
    id="name"
    name="name"
    >

    <button type="submit">
    Submit
    </button>

</form>

This is only a front-end example. It does not send information to a server.

7. Build Your First HTML Website

Create a file named index.html and paste this code. Save the file and open it in your browser. 

<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta name="viewport"
    content="width=device-width, initial-scale=1.0">

    <title>About Me</title>
</head>

<body>

    <h1>Hello! I am a student.</h1>

    <p>I am learning web development.</p>

    <h2>My Interests</h2>

    <ul>
        <li>Science</li>
        <li>Technology</li>
        <li>Creative Projects</li>
    </ul>

</body>
</html>

Project Challenges

  1. Change the website title.
  2. Add a new heading.
  3. Create a list of your learning goals.
  4. Add an image with alt text.
  5. Save and refresh the webpage.

8. Common HTML Beginner Mistakes

  • Forgetting required closing tags.
  • Putting visible content inside the head element.
  • Using headings only to change text size.
  • Not adding useful alt text to meaningful images.
  • Using tables for webpage layout.
  • Forgetting to save changes before refreshing.

10. Frequently Asked Questions

What is HTML?

HTML stands for HyperText Markup Language. It structures content on webpages.

Is HTML a programming language?

No. HTML is a markup language, not a programming language.

Can I learn HTML for free?

Yes. You can practise HTML using a free text editor and a web browser.

What should I learn after HTML?

Learn CSS to style webpages and JavaScript to add interactive features.

How long does it take to learn HTML?

It depends on your practice time and learning pace. Build small projects to improve your understanding.
