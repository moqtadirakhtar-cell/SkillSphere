Lesson 1 What is HTML?

HTML stands for HyperText Markup Language. It is the standard markup language used to create and structure webpages.

HTML tells a browser how webpage content is organised. For example, it defines headings, paragraphs, links, images, lists and forms.

HTML

Creates the structure and content of a webpage.

CSS

Controls colours, appearance and layout.

JavaScript

Adds interactive behaviour to webpages.

Browser

Reads HTML and displays the webpage.

Beginner tip: You can start learning HTML with a free text editor and a web browser. You do not need to buy special software.

Your first HTML line

<h1>Hello World!</h1>

This creates a main heading that displays the words "Hello World!" on a webpage.

Lesson 2 Basic HTML Structure

Every standard HTML document has a basic structure. The following example is a simple complete webpage. 

<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport"
        content="width=device-width, initial-scale=1.0">
  <title>My First Website</title>
</head>

<body>
  <h1>Hello World!</h1>
  <p>This is my first webpage.</p>
</body>

</html>

What do these parts mean?

  • <!DOCTYPE html> tells the browser to use modern HTML.
  • <html> is the root element of the page.
  • <head> contains information about the page.
  • <meta> provides information such as character encoding.
  • <title> sets the browser-tab title.
  • <body> contains the visible webpage content.
Remember: Most HTML elements have an opening tag and a closing tag. For example: <p>Text</p>.

Lesson 3 Common HTML Tags

HTML elements are created using tags. Here are some tags you will use frequently.

Heading Tags

<h1>Main Heading</h1>
<h2>Second Heading</h2>
<h3>Third Heading</h3>

HTML provides six heading levels, from <h1> to <h6>.

Paragraph Tag

<p>This is a paragraph.</p>

Bold and Emphasis

<strong>Important text</strong>
<em>Emphasised text</em>

Line Break

First line<br>
Second line

Horizontal Rule

<p>First topic</p>
<hr>
<p>Second topic</p>

Lesson 4 HTML Attributes

Attributes provide extra information about an HTML element. They are usually written inside the opening tag.

Example: Link Attribute

<a href="https://example.com">
  Visit Example
</a>

Here, href tells the browser where the link should go.

Example: Image Attributes

<img src="study.jpg"
     alt="Books on a study desk"
     width="300">
  • src specifies the image location.
  • alt provides alternative text.
  • width sets the image width.

Lesson 5 How to Add Links and Images

HTML Links

The anchor element creates a clickable link. 

<a href="https://example.com">
  Visit Example
</a>

Open a Link in a New Tab

<a href="https://example.com"
   target="_blank"
   rel="noopener noreferrer">
  Open Example
</a>

HTML Images

The image element displays an image on your webpage. 

<img
  src="study.jpg"
  alt="Books on a study desk"
  width="300"
>

The alt attribute provides alternative text for people who cannot see the image and for situations where the image cannot load.

Exercise: Add a link to a website you use for learning. Then add an image from your own project folder.

Lesson 6 HTML Lists and Tables

Unordered List

An unordered list displays items with bullet points.

<ul>
  <li>Science</li>
  <li>Mathematics</li>
  <li>English</li>
</ul>

Ordered List

An ordered list displays numbered items.

<ol>
  <li>Learn HTML</li>
  <li>Learn CSS</li>
  <li>Learn JavaScript</li>
</ol>

HTML Table

Tables organise information into rows and columns. 

<table>
  <tr>
    <th>Subject</th>
    <th>Hours</th>
  </tr>
  <tr>
    <td>Science</td>
    <td>2</td>
  </tr>
</table>
  • table creates a table.
  • tr creates a row.
  • th creates a header cell.
  • td creates a data cell.

Lesson 7 HTML Forms

Forms are used to collect information from visitors. This example creates a simple name form. 

<form>
  <label for="name">Your Name</label>

  <input
    type="text"
    id="name"
    name="name"
  >

  <button type="submit">
    Submit
  </button>
</form>

Common Input Types

<input type="text">
<input type="email">
<input type="password">
<input type="number">
<input type="date">
Important: This is a front-end HTML example. A form does not automatically save or send information to a server. That requires additional programming.

Lesson 8 Semantic HTML

Semantic HTML elements describe the meaning of different parts of a webpage. They help organise content clearly. 

<header>
  <h1>My Website</h1>
</header>

<nav>
  <a href="/">Home</a>
</nav>

<main>
  <article>
    <h2>My First Article</h2>
    <p>This is my article.</p>
  </article>
</main>

<footer>
  <p>My Website</p>
</footer>
  • header represents introductory content.
  • nav contains navigation links.
  • main contains the main page content.
  • article represents independent content.
  • footer represents footer information.

Lesson 9 Build Your First HTML Website

Now use what you have learned to create a simple student introduction webpage.

Step 1: Create a file

Open VS Code or another text editor. Create a new file named index.html.

Step 2: Paste this code

<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport"
        content="width=device-width, initial-scale=1.0">
  <title>About Me</title>
</head>

<body>

  <header>
    <h1>Hello! I am a student.</h1>
  </header>

  <main>
    <p>I am learning web development.</p>

    <h2>My Interests</h2>

    <ul>
      <li>Science</li>
      <li>Technology</li>
      <li>Creative Projects</li>
    </ul>
  </main>

  <footer>
    <p>My First HTML Project</p>
  </footer>

</body>
</html>

Step 3: Open your webpage

  1. Save the file as index.html.
  2. Find the file in your computer folder.
  3. Double-click it to open it in your browser.
  4. Change the text in VS Code, save and refresh the browser.

Project Challenges

  1. Change the page title.
  2. Add a new heading.
  3. Create a list of your learning goals.
  4. Add an image with useful alt text.
  5. Add a link to a learning website.

Lesson 11 Common HTML Beginner Mistakes

  • Forgetting required closing tags.
  • Putting visible page content inside the head element.
  • Using headings only to change text size.
  • Not adding useful alt text to meaningful images.
  • Using tables to create the whole webpage layout.
  • Forgetting to save changes before refreshing.
  • Writing a file name with the wrong extension.
Learning tip: When something does not work, check your spelling, opening tags, closing tags and file name.

13. Frequently Asked Questions

What is HTML?

HTML stands for HyperText Markup Language. It is used to structure content on webpages.

Is HTML a programming language?

No. HTML is a markup language, not a programming language.

Can I learn HTML for free?

Yes. You can practise HTML using a free text editor and a web browser.

What should I learn after HTML?

Learn CSS to style webpages and JavaScript to add interactive features.

Do I need a powerful computer to learn HTML?

No. You can begin learning HTML on a basic computer with a text editor and a web browser.

How long does it take to learn HTML?

It depends on your practice time and learning pace. Build small projects to improve your understanding.
